# PARRIT / LOGO-1.0 REV 03 — Production assets

Selected mark: 07 "The Bracket" — [P.] A registry entry: the P between
brackets, closed by the red terminal dot from PC-11. Chosen by P. Larmaraud
from the 10-proposal board (parrit-logo-10-propositions.html).

## Rules
- The dot is ALWAYS #E10600 in colour contexts; in one-colour contexts it
  becomes ink (never grayscale-simulated red).
- Brackets and P are geometry (paths), not live text — no font dependency.
- Institutional treatment only: the mark must never appear in code-editor or
  syntax-highlighting contexts that pull it toward "dev tool". It sits on
  documents, dossiers, briefings — the same surfaces as the registry line.
- Never letterspace, skew, outline-only, or recolour.

## Lockup guidance
Mark and wordmark both end in "P…" + red dot — side by side they read as a
repetition. Default usage: mark ALONE (favicon, app, seal positions, social
avatar) or wordmark ALONE (headers, documents). The combined lockup is
reserved for the rare cases needing both (legal footer, press kit).
