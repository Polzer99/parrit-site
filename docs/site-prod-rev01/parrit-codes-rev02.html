STATUT VERROUILLÉ — P. LARMARAUD

Ce document verrouille les codes de la marque Parrit pour exécution directe dans Figma et en code. Chaque code est numéroté PC-01 à PC-12, spécifié en valeurs exactes, et accompagné de ses interdictions. Territoire : The Command System. Principe directeur : l'identité émerge de la fonction — jamais de la décoration.

Note de révision — REV 02 Décision actée après exploration comparative de deux systèmes complets : le système carbone / blanc froid / rouge signal est retenu. Le système alternatif (papier chaud / orange calibration / Trace Rail) est écarté, à une greffe près : l'interaction Hold-to-Commit, intégrée en PC-07 et PC-09. Les statuts passent de « proposé » à « verrouillé ». Ce document fait référence pour la production — implémentation prévue via agents de code (Claude Code / Codex) : les tokens de PC-01 à PC-04 sont les variables sources.
PC-01

Le rouge Parrit

Verrouillé
Valeur
#E10600 (numérique) · variante pressée / hover / print offset : #B80500 · jamais de troisième rouge.
Règles
Toujours à 100 % d'opacité. Jamais teinté, jamais en dégradé, jamais en fond de section. Jamais de texte rouge sous 14 px sauf labels mono accompagnés d'une forme (PC-06). Une exception unique au fond rouge : le remplissage de commit (PC-07), parce qu'il est transitoire et actionné par l'utilisateur.
Contraste
Sur blanc froid : ≈ 4,5:1 — suffisant pour les composants, limite pour le texte courant → le rouge ne porte jamais de paragraphe. Sur carbone : réserver aux marques de 8 px et plus.
Sens
Décision requise · action en cours de commit · état critique · objet sélectionné · commission scellée. Rien d'autre.
#E10600 — signal · #B80500 — pressé

Deux registres
Document (blanc froid) : site, dossiers, standard, print — l'institution. Instrument (ink/carbon) : cockpit, Super App, démos live — le produit. Un artefact ne mélange jamais les deux registres, sauf pour mettre l'instrument en scène comme objet sur fond document.
Interdits
Aucune autre couleur. Pas de vert de succès, pas d'orange d'alerte — les états passent par la forme + le gris/rouge (PC-06). Pas de dégradés, nulle part.
PC-03

Typographie

À licencier — direction verrouillée
Recommandation
Söhne (Klim Type Foundry) pour tout le texte — Buch (400), Kräftig (500), Halbfett (600) — et Söhne Mono pour le registre technique. Une seule famille, deux voix : c'est le geste d'ingénierie. Alternative équivalente : ABC Diatype + Diatype Mono (Dinamo).
Transition
En attendant la licence : Geist + Geist Mono (gratuits, métriques proches). La bascule vers Söhne est un remplacement de variable, pas un redesign.
Échelle
DISPLAY 48–96 / 500 / −3,5 % · HEADING 21–24 / 600 / −1,5 % · BODY 13,5–15 / 400 / 0 · REGISTRY 10–12 mono / +14 % / CAPITALES
Interdits
Pas de serif. Pas d'italique. Jamais plus de deux graisses par écran.
PC-04

Grille & règles

Verrouillé
Base
Unité 8 px. Desktop : 12 colonnes, gouttières 24 px, marges 24–48 px, contenu max 1200 px. Mobile : 4 colonnes, marges 18 px.
Règles
Filets de 1 px partout (#DDE0E3 sur clair, #24282D sur sombre). Jamais de cartes flottantes, jamais d'ombres portées sauf mise en scène d'un instrument comme objet (une seule ombre autorisée : 0 40px 80px −40px rgba(10,11,12,.4)).
Rayons
0 px sur tout, sans exception, sauf les cadres de device (mockups téléphone). L'angle droit est un code.
PC-05

La ligne de registre

Verrouillé — motif propriétaire 1/2
Définition
Chaque artefact Parrit — écran, slide, dossier, post, bannière — porte une ligne d'identification en mono capitales : système, révision, statut, date.
Syntaxe
PARRIT / OS-0042 · SYS-018 · REV 03 · STATUS / OPERATIONAL · 2026
Rôle
Elle remplace le logo dans la plupart des contextes. C'est elle qui rend un screenshot Parrit reconnaissable — pas la répétition du wordmark.
PARRIT / OS-0042 · REV 03 · STATUS / OPERATIONAL
PC-06

États & iconographie

Verrouillé
Principe
Un état = forme + couleur, jamais la couleur seule. Trois états, trois formes : cercle gris = opérationnel · triangle = attention · carré rouge = critique / décision. Quatrième état dérivé : cercle plein = exécuté / journalisé.
Icônes
Aucune bibliothèque d'icônes sur les surfaces de marque. Dans le produit : icônes fonctionnelles uniquement, trait 1,5 px, jamais remplies, jamais illustratives. Pas de pictogrammes marketing, jamais.
Operational Attention Critical
PC-07

Le Parrit Frame & le Hold-to-Commit

Verrouillé — motif propriétaire 2/2 · REV 02
Le Frame
Quatre équerres rouges qui encadrent tout objet en attente de décision. Construction : ÉQUERRES 14 × 14 PX · TRAIT 2 PX · #E10600 · DÉCALAGE −1 PX. Un frame = une décision réelle. Jamais décoratif, jamais sur un titre, jamais imbriqué.
Hold-to-Commit
Greffe REV 02. Les actions conséquentes ne se cliquent pas : elles se tiennent 600 ms pendant que le rouge remplit le contrôle — un interrupteur à garde. Relâcher avant la fin annule sans conséquence. C'est l'interaction que Parrit possède : le geste physique de la décision.
Le cycle complet
FRAME OUVERT → HOLD 600 MS (REMPLISSAGE ROUGE) → COMMIT → FERMETURE DU FRAME 240 MS → LIGNE DE JOURNAL (EXECUTED · 09:14 · ACT-2841)
Accessibilité
Le hold doit être actionnable au clavier (maintien Espace/Entrée) et respecter prefers-reduced-motion (remplissage instantané, confirmation en deux temps).
Renouvellement contrat logistique — €120k / an
Maintenir 600 ms — relâcher annule

PC-09

Motion

Verrouillé · REV 02
Courbe
CUBIC-BEZIER(0.2, 0, 0, 1) — MÉCANIQUE, JAMAIS REBONDIE
Durées
MICRO 120 MS · TRANSITION 240 MS · SÉQUENCE 400 MS · HOLD 600 MS (LINÉAIRE)
L'animation signature
Le cycle de commit (PC-07) : remplissage rouge linéaire 600 ms → convergence et extinction des équerres 240 ms → apparition de la ligne de journal. C'est la seule animation à travailler finement — elle incarne « décision → action → trace ». Le remplissage est linéaire (progression d'un geste tenu), la fermeture est mécanique (courbe standard).
Autres motions
Boot séquentiel (lignes mono, 260 ms d'intervalle), apparitions progressives de l'information. Rien d'autre. Aucun parallax, aucun hover décoratif.

PC-11

Wordmark & sceau

À dessiner — direction verrouillée
Wordmark
PARRIT.AI — mono 600, +22 %, point rouge. Le point est la seule concession du rouge au logo. Présence minimale : une fois par artefact maximum, souvent zéro (la ligne de registre suffit).
Sceau
Carré rouge 9 px + BUILT TO THE PARRIT STANDARD en mono capitales. Uniquement sur un système livré et certifié — jamais en argument marketing sur une page de vente.
PARRIT.AI Built to the Parrit Standard
PC-12

Premier écran Super App

Verrouillé · REV 02
État
« What matters now » — lisible en 5 secondes. Quatre blocs maximum, chacun : chiffre mono 30 px / 500 + libellé 12,5 px gris + tag mono 9 px. Un seul bloc peut être rouge par écran.
Structure
STATUS BAR (HEURE · REGISTRE) → EN-TÊTE (CLIENT · LIVE) → 4 BLOCS D'ATTENTION → NAV : NOW / SYSTEMS / JOURNAL / ASK
Hiérarchie
L'ordre des blocs est l'ordre d'importance décidé par le système. Le bloc critique porte le frame s'il attend une décision, et sa vue de détail se termine par un Hold-to-Commit (PC-07), jamais par un bouton simple.
Nav « Ask »
Quatrième onglet réservé : l'entrée conversationnelle vers l'OS. À spécifier en v2 produit — hors scope marque.
