Design rationale

R-01

Core visual idea

Parrit speaks like an instrument, not like a website. Two registers only: cold-white documents (the institution) and carbon instruments (the product). Everything is set on fine rules and a registry line — the brand reads as engineering documentation for company infrastructure.

R-02

Proprietary elements

Three devices carry the identity without a logo: the Parrit Frame (red corner brackets that mark any object awaiting a decision — the frame closes when the action is journaled), the registry line (PARRIT / OS-0042 · REV 03 · STATUS) present on every artefact, and the Standard as a numbered specification (PS-01…PS-06) rather than marketing icons. Status always pairs shape with colour.

R-03

Why it supports the positioning

€40k–100k+ feels natural because nothing here resembles a tool you subscribe to. The dossier looks like commissioned infrastructure, the cockpit shows judgement (what deserves attention) rather than dashboards, and red is scarce enough that every appearance means money, risk or execution.

R-04

What to retain for the full design system

Keep: the Frame, the registry line, the two-register colour logic, the red law, shape-coded status, and the Standard-as-specification. Decide next: the definitive red (tested on both registers), a licensed type pair to replace Geist, and the motion spec for frame-close / journal confirmation — the one animation worth owning.
