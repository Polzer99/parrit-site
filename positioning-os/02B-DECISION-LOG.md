## Règle de mise à jour

Aucun changement de positionnement, d'offre, de storytelling ou de copy ne doit être appliqué silencieusement.

Chaque changement est ajouté à ce registre **avant** de modifier les documents concernés. La ligne du registre nomme les documents à actualiser ; tant qu'ils ne le sont pas, l'écart est visible ici plutôt que caché dans le code.

Cette règle répond au défaut le plus coûteux du corpus, documenté en K10 de `positioning-research/07-contradictions.md` : une décision déployée dans le code pendant que la spec la dit encore ouverte. Personne ne rouvre un sujet dont le code affirme qu'il est réglé.
